# 🤖 Agno AI Agent — Secure Telegram Edition v3.1

Многопользовательский ИИ-агент на **Agno + OpenRouter** с CLI, Telegram, SQLite, персональной RAG-базой LanceDB и безопаснее устроенной обработкой загружаемых документов.

GitHub: https://github.com/Dasgam/agno-ai-agent

## Главное изменение

**Загружаемый PDF/DOCX никогда не открывается парсером внутри процесса Telegram-бота.** Файл получает временное случайное имя в карантине, затем отдельный Docker-контейнер без сетевого подключения извлекает только UTF-8 текст. Бот индексирует уже **текст**, а исходный файл удаляет.

Это снижает риск эксплуатации уязвимостей в парсерах, но **не является стопроцентной защитой от всех вредоносных файлов и не заменяет антивирус**. В комплекте нет ClamAV/полноценного AV-сканера и CDR. Для публичного запуска на сервере необходимы регулярные обновления Docker, библиотек и ОС, мониторинг и независимая проверка безопасности. Docker Desktop/движок Docker должен быть доверенным, а контейнерный sandbox не следует считать полной заменой отдельной виртуальной машины.

### Защита файлов

- Белый список форматов: **PDF, DOCX, TXT, MD, CSV**; `.exe`, `.zip`, `.docm`, архивы и скрипты отклоняются.
- Размер документа **до 8 МБ**, PDF **до 120 страниц**, **до 250 000 символов текста**.
- Проверка сигнатуры PDF/DOCX, ZIP-бомб и вложенных исполняемых объектов DOCX.
- Контейнер обработки: `network_mode: none`, `read_only: true`, `cap_drop: ALL`, `no-new-privileges`, non-root, `512 MB RAM`, `1 CPU`, ограничение PID и время обработки одного файла 45 секунд.
- Контейнеру не передаются API-ключи, SQLite или доступ к базе знаний. Он видит только папки карантина и результатов.
- Бот не сохраняет оригиналы: сохраняются текст и его индекс. Личная RAG-база и SQLite у каждого Telegram ID раздельные.
- Если Docker-обработчик не запущен, **загрузка отключена**, небезопасного резервного способа разбора нет.
- В режиме вопроса по документу агенту недоступны веб-поиск и другие внешние инструменты. Фрагменты файла считаются недоверенными данными, а не инструкциями.
- Для каждого Telegram ID: **60 вопросов и 10 файлов в день (UTC)**, максимум **20 сохранённых документов**.
- В консольной версии `/add` и `/docs` тоже отправляют документы в sandbox. Произвольная загрузка URL в CLI отключена; `/seed` оставлен для заранее настроенного официального источника Agno.

**Остаточные риски:** файлы кратковременно хранятся в карантине на диске хоста; вредоносный документ может эксплуатировать неизвестную уязвимость Docker или его компонентов; содержимое текста может пытаться манипулировать моделью. Контейнер — общая изоляция процесса обработки, **не отдельная микровиртуальная машина на каждый файл**. Пользователь с доступом администратора к компьютеру видит сохранённые тексты и базы. Фрагменты текста отправляются OpenRouter для ответов.

## ✨ Ответы и Markdown

- Telegram: преобразование Markdown модели в безопасный **Telegram HTML** с поддержкой **жирного, курсива, заголовков, списков, цитат, блоков кода и ссылок**.
- Длинные ответы автоматически разделяются, HTML-теги корректно закрываются.
- Ссылки проверяются: допускаются только `https://` и `http://`; сырой HTML от модели не выполняется.
- CLI: **Rich Markdown** с подсветкой программного кода.

## 1. Установка — Windows CMD + Docker Desktop

Установи **Python 3.12** и **Docker Desktop** (режим Linux containers). Скачай код или клонируй репозиторий:

```cmd
git clone https://github.com/Dasgam/agno-ai-agent.git
cd agno-ai-agent
py -3.12 -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
copy agent\.env.example agent\.env
```

Если переносишь файлы из ZIP в существующий проект — оставь свой `agent/.env` и папку `agent/data/` без изменений. **Не удаляй старые базы данных.** Лучше сохранить резервную копию `agent/data/` перед обновлением.

В `agent/.env` впиши свои ключи и ID:

```env
OPENROUTER_API_KEY=your_openrouter_api_key
ID_MODEL=nvidia/nemotron-3.5-lightning:free
TELEGRAM_BOT_TOKEN=your_NEW_telegram_bot_token
TELEGRAM_OWNER_ID=111111111,222222222,333333333
```

Укажи действительные ID через запятую. Бот отвечает только этим пользователям в личном чате. Команда `/myid` доступна всем для получения своего ID.

**Важно:** ранее Telegram-токен был опубликован в логах. Старый токен следует отозвать через [@BotFather](https://t.me/BotFather) и заменить новым. `agent/.env` находится в `.gitignore`.

## 2. Запуск изолированного обработчика

Из **корня проекта**, когда активировано виртуальное окружение:

```cmd
python agent\prepare_sandbox.py
docker compose up -d --build document-sandbox
docker compose ps
docker compose logs --tail=30 document-sandbox
```

Убедись, что контейнер запущен. **Никакой токен или `.env` не копируются внутрь его Docker-образа** — это обеспечивает `.dockerignore`.

**Важно на Linux:** `outbox` должен быть доступен на запись непривилегированному пользователю контейнера. По умолчанию это UID/GID `1000:1000`. При необходимости установи владельца и `SANDBOX_UID`/`SANDBOX_GID` для Compose в соответствии с локальной учётной записью. Не запускай контейнер от root только ради исправления прав.

Чтобы остановить обработчик:

```cmd
docker compose down
```

При остановленном обработчике загрузка файлов будет отклоняться, но обычные вопросы останутся доступны.

## 3. Запуск Telegram или CLI

```cmd
python agent\telegram_bot.py
```

Или для отдельного терминала:

```cmd
python agent\agent_cli.py
```

Telegram-бот работает через polling, пока запущен процесс. Не запускай две копии одного бота с одинаковым токеном одновременно.

### Команды бота

| Команда | Действие |
|---|---|
| `/start` | Начало работы |
| `/help` | Справка |
| `/myid` | Показать мой Telegram ID |
| `/models` | Список моделей |
| `/model 9` | Выбрать модель |
| `/new` | Новый диалог |
| `/status` | Текущая модель и документ |
| `/files` | Мои документы |
| `/use 1` | Выбрать ранее загруженный документ |

Пример: отправь `lecture.pdf` как документ и спроси «О чём этот файл?» или «Назови главные разделы». Бот не будет выдавать содержимое документа другого пользователя.

## 🔐 Данные и ограничения

- `agent/data/sessions.sqlite3` — сохранение диалогов Agno.
- `agent/data/telegram_state.sqlite3` — настройки и личный список файлов Telegram.
- `agent/data/telegram_rag/user_<ID>/` — персональный векторный индекс.
- `agent/data/telegram_extracted_text/<ID>/` — текст загруженных документов.
- `agent/data/sandbox_spool/inbox/` — временные оригиналы в карантине.
- `agent/data/sandbox_spool/outbox/` — временные результаты обработчика.
- Для ранее загруженных документов v3.0 действуют прежние записи (оригиналы могли быть сохранены в `agent/documents/telegram/`). Старые оригиналы **не удаляются автоматически**; проверь и при необходимости удали их после резервного копирования.
- Сканированные PDF без текстового слоя не поддерживаются (OCR отключён).

Тесты проверяют структуру Markdown/HTML, отказ поддельного PDF, ZIP-бомбу DOCX и текстовый файл. **Тесты не доказывают отсутствие уязвимостей**. Нужны также интеграционное тестирование с Docker Desktop, Telegram и OpenRouter и обновление зависимостей.
